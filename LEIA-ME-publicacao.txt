LUXX STORE AD — publicação automática

Arquivos:
- worker.js: código para substituir o Hello World do Worker luxx-store-api.
- schema.sql: tabela necessária no D1.
- editor-luxx-publicacao.html: cópia do editor com o botão "Salvar e Publicar" adicionado.

Configuração do Worker:
Bindings:
- D1: variável DB
- R2: variável bucket (minúsculo)

Secrets:
- GITHUB_TOKEN
- PUBLISH_SECRET

O Worker publica index.html no branch main do repositório público trindadematheus71-del/LUXX-STORE-AD-.
O Cloudflare Pages só fará deploy automático se o projeto Pages estiver conectado a esse repositório e branch.

Importante:
1. Não coloque os valores dos Secrets no HTML nem os envie por mensagem.
2. O botão pede PUBLISH_SECRET no momento da publicação.
3. Antes de publicar, execute schema.sql no D1.
4. Confirme no GitHub que o branch principal é main. Se for outro, ajuste BRANCH em worker.js.
5. Confirme que o token GITHUB_TOKEN tem acesso Contents: Read and write ao repositório LUXX-STORE-AD-.
6. Teste primeiro com poucos produtos e imagens pequenas.

O HTML original foi preservado; a única alteração funcional é o botão e seu evento de publicação.
